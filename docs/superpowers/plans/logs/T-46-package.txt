4. 缺陷登记（未修复，按任务要求）
--------------------------------------------------------------------------------

D-1  越界条目 AGENTS.md
     规则：design §12.3 允许清单无此项，spec 亦未申请；§12.3 末段「任何不在此列
           的文件面都必须在 spec 中显式申请，否则视为越界」。
     来源：工具链 `moon new` 模板文件，随 T-02 的模块根创建一起提交（commit
           061bc9d feat(module): create MoonBit module root under lib/）。
     额外矛盾：计划 §W1b（plan.md:201）明确把 AGENTS.md 定位在**仓库根**，不是
           模块目录内；现同时存在 lib/AGENTS.md，属落点错误。
     影响：发布包内含面向 AI/贡献者的开发指引，与库使用者无关；且暴露内部工程约定。
     建议（不属本任务文件面）：移到仓库根或加入 lib/.gitignore。

D-2  越界条目 cmd/main/{main.mbt, moon.pkg, pkg.generated.mbti}
     规则：design §12.3 WB9 只允许「可选 cmd/example」；WB11 只允许 cmd/gate/。
           cmd/main 未在 spec 中申请。
     来源：工具链模板脚手架（main.mbt 内容为 `println("Hello")`，moon.pkg 的
           import 段整体被注释），随 061bc9d 一起提交。
     影响：发布包内包含一个与本库无关的 "Hello" 可执行包；同时把模板残留物
           当成对外文件面。
     建议：删除该目录（或按 WB9 改名为 cmd/example 并在 spec 申请）。

D-3  观察项（非越界，不计入 fail）：NOTICE 缺失
     design §12.3 WB10 允许 LICENSE、NOTICE，但 zip 内无 NOTICE。
     允许清单是上限，故不构成越界；但 spec §4.8.3 的 P-1 分支（假设采用）要求
     「附 NOTICE 与逐文件许可声明」，当前该条件性契约未满足。因 P-1 仍属未决
     假设（PRD-A 七、开放问题第 3 行），本任务只登记，不判 fail。

D-4  观察项（非越界）：.gitignore 与 .gitattributes 未入包
     二者在 §12.3 允许清单内（「行尾与忽略」行），但 moon package 会排除
     .gitignore 命中的路径，故不出现。属预期，不构成缺陷。
