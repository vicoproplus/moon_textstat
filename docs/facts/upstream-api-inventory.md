### Which function implements which metric

- **Word count** — `count_words` (`_count_words.py:39-46`) = `len(list_words(...))`.
  Defaults: `rm_punctuation=True`, contractions and hyphenated words count as one.
- **Sentence count** — `count_sentences` (`_count_sentences.py:24-32`).
- **Syllable count** — `count_syllables` (`_count_syllables.py:23-34`).
- **Character count** — `count_chars` (`_count_chars.py:25-27`);
  `letter_count` (`_count_letters.py:25-26`) is a separate "letters only" count.
- **Difficult-word count** — `count_difficult_words` (`_count_difficult_words.py:34-36`),
  driven by `list_difficult_words`/`set_difficult_words` and `is_difficult_word`.
- **Polysyllable count** — `count_polysyllable_words`
  (`_count_polysyllable_words.py:26`, `>= 3` syllables).
- **Reading time** — not in `counts`: `backend/metrics/_reading_time.py:8,23`
  = `ms_per_char * count_chars(text, ignore_spaces=True) / 1000`.
- **Tokenization** — `list_words` (`_list_words.py:48-56`).
- **Normalization** — `remove_punctuation` (`_remove_punctuation.py:33-42`);
  lowercasing is opt-in in `list_words` (`_list_words.py:52-53`) and unconditional in
  `is_difficult_word` (`_is_difficult_word.py:41`).

### 1. Flesch Reading Ease

- Public: `textstat/textstat.py:547-560`.
- Backend: `backend/metrics/_flesch_reading_ease.py:11-37`.

```python
lang_root = get_lang_root(lang)
sentence_length = words_per_sentence(text)
syllables = syllables_per_word(text, lang)

if sentence_length == 0 or syllables == 0:
    return 0.0

return (
    get_lang_cfg(lang_root, "fre_base")
    - get_lang_cfg(lang_root, "fre_sentence_length") * sentence_length
    - get_lang_cfg(lang_root, "fre_syll_per_word") * syllables
)
```

Calls `words_per_sentence` (`_words_per_sentence.py:26-29`) and `syllables_per_word`

### 3. Gunning Fog

- Public: `textstat/textstat.py:865-878`.
- Backend: `backend/metrics/_gunning_fog.py:12-36`.

```python
syllable_threshold = int(get_lang_cfg(lang, "syllable_threshold"))
diff_words = count_difficult_words(text, lang, syllable_threshold)
tot_words = count_words(text)

try:
    per_diff_words = 100 * diff_words / tot_words
except ZeroDivisionError:
    return 0.0

return 0.4 * (words_per_sentence(text) + per_diff_words)
```

Calls `count_difficult_words`, `count_words`, `words_per_sentence`.

Thresholds: `en` 3, `pl` 4, `hu` 5 (`constants.py:20,52,63`); other languages inherit
the English 3 through the `get_lang_cfg` fallback (`_get_lang_cfg.py:26-30`).
Constant `0.4`.

Deviation: the "complex word" definition is *not* the textbook "3+ syllables"; it is
"not in the Dale-Chall easy-word list **and** at least `syllable_threshold` syllables"
(`_is_difficult_word.py:38-51`). Proper nouns and inflections therefore inflate the
count.

### 4. SMOG

- Public: `textstat/textstat.py:607-630`.
- Backend: `backend/metrics/_smog_index.py:9-40`.

```python
sentences = count_sentences(text)

poly_syllab = count_polysyllable_words(text, lang)
try:
    return (1.043 * (30 * (poly_syllab / sentences)) ** 0.5) + 3.1291
except ZeroDivisionError:
    return 0.0
```

Calls `count_sentences`, `count_polysyllable_words` (`_count_polysyllable_words.py:26`,
`>= 3` syllables). Constants `1.043`, `30`, exponent `0.5`, `+3.1291`.

Deviations:
- No 30-sentence window: all sentences are used, there is no sampling of the first 10
  sentences every 10th sentence, and **no 3-sentence minimum**.
- No clamping of the result.
- Docstring at `textstat.py:628` says "more than 3 syllables", but the implementation is
  `>= 3`.
- Empty text → `0.0` (because `count_sentences("") == 0`); any non-empty text with zero
  polysyllables → exactly `3.1291` (see whitespace-only / punctuation-only oracle rows).

### 6. Coleman-Liau

- Public: `textstat/textstat.py:632-654`.

### 7. Linsear Write

- Public: `textstat/textstat.py:680-721`; defaults `strict_lower=False`,
  `strict_upper=True` (`textstat.py:681`).
- Backend: `backend/metrics/_linsear_write_formula.py:12-83`.

```python
text_list = list_words(text, rm_punctuation=False)

words_list = []
i_text = 0
if strict_upper and len(text_list) > 100:
    while (i_text < len(text_list)) and (len(words_list) < 100):
        word = remove_punctuation(text_list[i_text], rm_apostrophe=False)
        i_text += 1
        if len(word) > 0:
            words_list.append(word)
else:
    words_list = list_words(text, rm_punctuation=True)
    i_text = len(text_list)

if strict_lower and len(words_list) < 100:
    return 0.0

easy_word = 0
difficult_word = 0
for word in words_list:
    n_syll = count_syllables(word, lang)
    if n_syll >= 3:
        difficult_word += 1
    elif n_syll > 0:
        easy_word += 1

text = " ".join(text_list[:i_text])

try:
    number = float((easy_word * 1 + difficult_word * 3) / count_sentences(text))
except ZeroDivisionError:
    return 0.0

if number <= 20:
    number -= 2

return number / 2
```

Calls `list_words`, `remove_punctuation`, `count_syllables`, `count_sentences`.
Constants: 100-word cap, weight `3`, `>= 3` syllable cut, `-2` when intermediate
`<= 20`, final `/2`.

Deviations: the 100-word truncation is **on by default**; zero-syllable tokens are
silently skipped; the sentence denominator is computed on the truncated text
(`text = " ".join(text_list[:i_text])`); punctuation-only input yields `-1.0`
(0 easy + 0 hard, `<= 20` → `-2`, then `/2`).

### 8. Dale-Chall

- Public: `textstat/textstat.py:829-863`.
- Backend: `backend/metrics/_dale_chall_readability_score.py:10-56`.

```python
word_count = count_words(text)
hard_count = count_difficult_words(text, lang, syllable_threshold=0)

try:
    per_difficult_words = 100 * hard_count / word_count
except ZeroDivisionError:
    return 0.0

score = (0.1579 * per_difficult_words) + (0.0496 * words_per_sentence(text))

if per_difficult_words > 5:
    score += 3.6365
return score
```

Calls `count_words`, `count_difficult_words` (backend default `unique=False`,
threshold forced to **0**), `words_per_sentence`. Constants `0.1579`, `0.0496`,
`3.6365`, cutoff `> 5`.

Deviations (also in the docstring, `textstat.py:832-838`):
- The easy list is the vendored `resources/en/easy_words.txt` with **2,941** entries,
  not the canonical 3,000-word Dale-Chall list.
- Regular inflections are not matched, so `dogs` is difficult even though `dog` is easy.
- Proper nouns are difficult.
- Because `syllable_threshold=0`, every out-of-list token counts, including `pm`,
  `USA`, `eg`.
- `dale_chall_readability_score_v2` (`textstat.py:964-979`,
  `_dale_chall_readability_score_v2.py:10-35`) uses the same constants but the default
  threshold 2, so its difficult-word set is a strict subset.

## G. Sentence / word / syllable definition conventions

### Sentence

`backend/counts/_count_sentences.py:24-32`:

```python
if len(text) == 0:
    return 0

ignore_count = 0
sentences = re.findall(r"\b[^.!?]+[.!?]*", text, re.UNICODE)
for sentence in sentences:
    if count_words(sentence) <= 2:
        ignore_count += 1
return max(1, len(sentences) - ignore_count)
```

- Terminators: only `.`, `!`, `?`. Newlines, `;`, `:`, `…` do not terminate.
- The regex requires a `\b` word boundary before the run of non-terminators, so leading
  punctuation can be skipped and a leading digit run like `3.14` splits after `3.`.
- Any candidate with **2 or fewer words** (punctuation removed) is discarded.
- `max(1, ...)`: any non-empty string yields at least 1 sentence; `""` yields 0.
- No abbreviation handling whatsoever: `Dr.`, `Prof.`, `p.m.`, `U.S.`, `e.g.`, `J. R. R.`
  all split. Verified: `"Dr. Smith went to Washington. He met Prof. Jones at 5 p.m. on
  Tue. ..."` → 6 sentences, `"U.S.A. is big."` → 1, `"e.g. this. U.S. that."` → 1.
- Verified short-sentence collapse: `"Hello world! How are you?"` → **1**;
  `"one. two. three. four."` → 1; `"A. B. C. D. E."` → 1;
  `"Hi. There. Ok then."` → 1; `"Sentence one is here. Sentence two is here. Go."` → 2.
- `"   \n\t "` (whitespace only) → 1, because it is non-empty and `findall` returns
  nothing, so `max(1, 0)` applies.

### Word

`backend/selections/_list_words.py:48-56`:

```python
if split_hyphens:
    text = re.sub(r"-", " ", text)
if rm_punctuation:
    text = remove_punctuation(text, rm_apostrophe=rm_apostrophe)
if lowercase:
    text = text.lower()
if split_contractions:
    text = re.sub(RE_CONTRACTION_APOSTROPHE, " ", text)
return text.split()
```

`backend/transformations/_remove_punctuation.py:33-42`:

```python
if rm_apostrophe:
    # remove all punctuation
    punctuation_regex = r"[^\w\s]"
else:
    # remove non-apostrophe single quotation marks
    text = re.sub(RE_NONCONTRACTION_APOSTROPHE, "", text)
    # remove all punctuation except apostrophes
    punctuation_regex = r"[^\w\s\']"

text = re.sub(punctuation_regex, "", text)
```

- Splitting is `str.split()` on arbitrary whitespace; no Unicode word segmentation.
- `\w` is Unicode-aware and includes digits and `_`, so `3.14` → `314`,
  `$1,299.99` → `129999`, `12.5%` → `125`. These count as words.
- Hyphens are always removed by `remove_punctuation`, fusing compounds:
  `well-known` → `wellknown`, `state-of-the-art` → `stateoftheart`,
  `covid-19` → `covid19`. Only `split_hyphens=True` (replacing `-` with a space
  *before* punctuation removal) avoids this.
- Apostrophes: `RE_CONTRACTION_ENDINGS = r"[tsd]|ve|ll|re"`,
  `RE_CONTRACTION_APOSTROPHE = r"\'(?=" + endings + ")"`,
  `RE_NONCONTRACTION_APOSTROPHE = r"\'(?!" + endings + ")"`
  (`backend/utils/constants.py:67-69`).
  With `rm_apostrophe=False`, apostrophes before `t/s/d/ve/ll/re` survive
  (`don't`, `it's`, `we'll`, `I've`, `you're`, `he'd`) and all others are deleted
  (`'quoted'` → `quoted`, `rock 'n' roll` → `rock n roll`).
  With `rm_apostrophe=True`, everything is deleted (`don't` → `dont`).
- `split_contractions=True` splits only at apostrophes before those endings
  (`don't` → `don t`, `it's` → `it s`); it is a no-op if apostrophes were already
  removed (docstring `_list_words.py:22-25`).
- Case is preserved by default; only syllable counting (`lowercase=True`,
  `_count_syllables.py:28`) and `is_difficult_word` (`_is_difficult_word.py:41`)
  lowercase. This matters for the Dale-Chall list lookup and for CMUdict keys.
- Punctuation-only tokens disappear under the default `rm_punctuation=True`
  (`" .? "` → `[]`, `lexicon_count` → 0) but are counted with
  `rm_punctuation=False` (used by `chars_per_word` and Linsear's first pass).

### Syllable

`backend/counts/_count_syllables.py:23-34`:

```python
if not text:
    return 0
cmu_dict = get_cmudict(lang)
pyphen = get_pyphen(lang)
count = 0
for word in list_words(text, lowercase=True):
    try:
        cmu_phones = cmu_dict[word][0]
        count += sum(1 for p in cmu_phones if p[-1].isdigit())
    except (TypeError, IndexError, KeyError):
        count += len(pyphen.positions(word)) + 1
return count
```

- For `en*`, CMUdict is consulted per lowercased word; the **first** pronunciation
  (`[0]`) is used and phonemes whose last character is a digit (stress marker) are
  counted.
- Any miss — including the `None` dictionary for non-English languages, which raises
  `TypeError` on subscripting — falls back to Pyphen:
  `len(positions(word)) + 1`.
- No silent-e rules, no vowel-group heuristics, no explicit exception table exist in
  this repository. Those decisions are entirely delegated to CMUdict (English) and
  Pyphen dictionaries (everything else).
- Hyphenated compounds reach this function already fused by `list_words`, so they are
  one token (e.g. `wellknown` is a CMUdict miss → Pyphen `positions('wellknown') == [4]`
  → 2 syllables).
- Verified fallbacks: `pm` → 2 (Pyphen, no positions), `usa` → 3, `text_a` → 2
  (Pyphen `positions('text_a') == [3]`), `日本語` → 1, `5` → 1.
- `count_syllables("", lang)` → 0 by the early return.

### Other numeric conventions

- `count_polysyllable_words`: `count_syllables(w, lang) >= 3`
  (`_count_polysyllable_words.py:26`).
- `count_monosyllable_words`: `== 1` (`_count_monosyllable_words.py:24`).
- `is_difficult_word`: reject multi-token input, lowercase, reject if in easy set,
  reject if `count_syllables < syllable_threshold`, else True
  (`_is_difficult_word.py:35-51`).
- `count_chars`: `len(re.sub(r"\s", "", text))` when `ignore_spaces` else `len(text)`
  (`_count_chars.py:25-27`).
- `count_letters`: strip all `\s`, then `remove_punctuation(text, rm_apostrophe=True)`,
  then `len(...)` (`_count_letters.py:25-26`) — digits and `_` remain.
- `reading_time`: `ms_per_char * count_chars(text, ignore_spaces=True) / 1000`,
  default `ms_per_char=14.69` (`_reading_time.py:23`, `textstat.py:1017`).
- `text_standard`: collects floor/ceil/round of FK, SMOG, Coleman-Liau, ARI,
  Dale-Chall, Linsear, Gunning Fog plus one FRE band value, then
  `Counter(...).most_common(1)`; ties resolve to the value seen first
  (`_text_standard.py:34-108`). The public wrapper clamps to `[1, 18]` and formats
  `"{lower}{suffix} and {upper}{suffix} grade"` with `lower = int(v) - 1`
  (`textstat.py:1002-1015`), which is why `text_standard("")` returns
  `"0th and 1st grade"`.
- Rounding: `_legacy_round` returns the float unchanged while `__round_points is None`
  (`textstat.py:101-103`), so Python binary artifacts such as
  `116.14500000000001` are part of the observable contract.
